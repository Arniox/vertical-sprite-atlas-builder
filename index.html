Notes

The checkerboard cleanup samples image colours and makes detected fake checker pixels transparent. It is adjustable because no browser tool can perfectly know whether a grey pixel is fake background or real artwork. 

Normal atlas workflow:
1. Drop sprite strips.
2. Reorder them.
3. Optional: open each strip with Edit and adjust scale/nudge.
4. Optional: cleanup checkerboard, trim transparency, normalize height/width.
5. Add final strip padding if wanted.
6. Export PNG or WebP.

Codex pet workflow:
1. Load up to 9 strips in this row order:
   idle, running-right, running-left, waving, jumping, failed, waiting, running, review.
2. Open each strip and set "Codex source frames" if it is not 8.
3. Choose "Codex pet package (.zip)".
4. Export.
5. Put the unzipped folder under ~/.codex/pets/ or %USERPROFILE%\.codex\pets\.
